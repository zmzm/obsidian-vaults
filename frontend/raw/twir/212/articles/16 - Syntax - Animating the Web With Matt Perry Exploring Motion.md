Summary:
This Syntax podcast episode features Matt Perry, creator of Motion (formerly Framer Motion), discussing the evolution of the library, its open source transition, and the future of web animation. Topics include Motion’s technical underpinnings, performance, testing, influences from other animation libraries, and upcoming features. The conversation also touches on animation best practices and the broader web animation landscape.

Key takeaways:
- Motion is a leading React animation library, now open source and focused on intuitive, performant APIs.
- Built on WAAPI and inspired by libraries like GSAP, Anime.js, and Svelte.
- Emphasis on performance, testing, and future directions for web animation.
- Valuable insights for teams building animated UIs in React.
