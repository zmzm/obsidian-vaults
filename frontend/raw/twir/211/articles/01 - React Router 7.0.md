# Item 1: React Router 7.0

Source: [https://remix.run/blog/react-router-v7](https://remix.run/blog/react-router-v7)

Summary:
React Router v7 has been released, bringing many features from Remix back into the core router. It introduces a "framework mode" with enhanced type safety, server rendering, bundle optimization, and a robust development environment. The upgrade path is smooth for both React Router v6 and Remix v2 users, and new templates are available for rapid app setup. Documentation and upgrade guides are provided for both existing and new users.

Key takeaways:
- React Router v7 integrates Remix features, including a compiler (Vite-based), SSR, and improved type safety.
- Offers both "library" and "framework" modes, with templates for common setups (SSR, HMR, Tailwind, deployment pipelines).
- Upgrade guides are available for v6 and Remix v2 users.
- New apps can choose between minimal or full-featured setups.
