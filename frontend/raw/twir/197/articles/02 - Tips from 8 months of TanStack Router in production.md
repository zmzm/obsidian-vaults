# Item 2: Tips from 8 months of TanStack/Router in production

Source: [https://swizec.com/blog/tips-from-8-months-of-tan-stack-router-in-production/](https://swizec.com/blog/tips-from-8-months-of-tan-stack-router-in-production/)

Summary:
This article shares practical lessons and patterns from extensive production use of TanStack Router. It covers routing philosophy, code organization, data loading strategies, and the importance of not over-abstracting early. The focus is on building robust, maintainable apps with type-safe routing, coordinated data loading, and a clear separation of concerns.

Key takeaways:
- Use URLs to represent significant UI state and ensure reproducibility via direct links.
- Organize code by file-based routing and vertical modules; avoid deep relative imports.
- Leverage router-level loaders for page data, suspense queries for component data, and share query logic for consistency.
- Generalize code only after repeated patterns emerge to keep abstractions natural.
