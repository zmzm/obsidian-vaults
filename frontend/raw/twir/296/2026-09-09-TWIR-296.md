# This Week in React #296 (MOC)

## TL;DR
- React 19.3 is now available, bringing the stabilization of the View Transitions and Fragment Refs APIs
- React DevTools 8.0 introduces several major updates, including enabling the Suspense tab by default, removing the Timeline profiler in favor of browser-native Performance panel tracks, and adding a React Element pane to the browser’s Elements panel
- The react-devtools-cdt-mcp package is an experimental library for integrating React inspection and profiling tools with Chrome DevTools MCP (Multi-Client Protocol)
- This documentation update adds missing options for server-side rendering (SSR) and hydration APIs in React, including formState, importMap, onHeaders, maxHeadersLength, and improved nonce handling
- Next.js upgrades its web-vitals dependency to v6.x, enabling reporting of soft navigations for key metrics (CLS, INP, LCP) and improving attribution via navigationURL
