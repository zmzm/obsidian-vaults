# Item 1: TanStack Start Adds First-Class Rsbuild Support

Source: [https://tanstack.com/blog/start-adds-rsbuild-support](https://tanstack.com/blog/start-adds-rsbuild-support)

Summary:
TanStack Start now supports Rsbuild 2 as a first-class build tool, alongside Vite. This allows teams to choose between Vite and Rsbuild (built on Rspack, Webpack-like) for their React or Solid apps, integrating Start via a plugin system. The adapter was developed in collaboration with the Rsbuild and Rspack teams, and the integration pattern is familiar to those using Start with Vite. This flexibility helps teams migrate incrementally and retain their preferred build tool while leveraging Start’s features.

Key takeaways:
- TanStack Start supports both Vite and Rsbuild, offering flexibility for teams with different build tool preferences.
- The Rsbuild adapter enables native integration for teams familiar with Webpack/Rspack ecosystems.
- The plugin system ensures that future framework adapters can follow the same integration path.
- Teams can migrate to Start without overhauling their entire build setup, easing adoption.
