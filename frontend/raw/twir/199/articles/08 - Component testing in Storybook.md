# Item 8: Component testing in Storybook

Source: [https://storybook.js.org/blog/component-testing/](https://storybook.js.org/blog/component-testing/)

Summary:
Storybook advocates for component testing as a middle ground between unit and end-to-end (E2E) testing. Component tests render UI components in the browser, allowing for realistic interaction and assertions without the overhead of full E2E tests. The article explains where component testing fits in the testing pyramid and provides practical examples, highlighting its benefits for UI confidence and maintainability.

Key takeaways:
- Component tests offer browser fidelity with the speed of unit tests.
- They complement, not replace, E2E and unit tests.
- Useful for testing a wide range of UI states efficiently.
- Storybook and similar tools enable component testing in real browsers.
