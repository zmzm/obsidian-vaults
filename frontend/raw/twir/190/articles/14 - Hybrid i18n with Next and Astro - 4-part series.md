# Item 14: Hybrid i18n with Next and Astro - 4-part series

Source: [https://www.ericburel.tech/blog/hybrid-i18n-next-astro-1](https://www.ericburel.tech/blog/hybrid-i18n-next-astro-1)

Summary:
This series explores building an optimized internationalization (i18n) system for hybrid frameworks like Next.js and Astro, focusing on minimizing overfetching and improving performance. The first part analyzes current token loading strategies, their inefficiencies, and sets the stage for solutions involving server components and alternative context patterns.

Key takeaways:
- Large translation dictionaries often lead to overfetching and performance issues.
- The series aims to design a system that loads only the necessary translation tokens per page.
- Hybrid frameworks require different i18n strategies for server and client components.
- Future parts promise practical solutions using React cache and optimized client-side loading.
