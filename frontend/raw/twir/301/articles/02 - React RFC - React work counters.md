# Item 2: React RFC - React work counters

Source: [https://github.com/reactjs/rfcs/pull/284](https://github.com/reactjs/rfcs/pull/284)

Summary:
A new RFC proposes adding runtime counters to React, providing observability into component updates, renders, commits, and state changes—akin to a CPU profiler for React. This would help developers and SREs gain quantitative insights into app behavior in production, beyond what DevTools currently offers. Previous similar efforts stalled, but there is renewed interest and some third-party tools already attempt this.

Key takeaways:
- RFC aims to expose granular runtime metrics for React apps (updates, renders, commits, etc.).
- Intended to improve transparency and enable better profiling/monitoring, especially in production.
- Builds on past efforts and existing tools, but seeks a standardized, first-party solution.
- Could benefit both performance tuning and incident analysis.
