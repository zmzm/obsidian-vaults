# Item 1: Next.js 16.3 - Instant Navigations and 90% less RAM in dev

Source: [https://nextjs.org/blog/next-16-3](https://nextjs.org/blog/next-16-3)

Summary:
Next.js 16.3 delivers major improvements across development and production workflows, including up to 90% less RAM usage in dev, faster builds, improved server-side rendering, and a suite of "Instant Navigations" tools for SPA-like responsiveness. The release introduces features like partial prefetching, better static asset caching, custom error boundaries, and built-in glob imports. AI agent integration is enhanced with versioned docs and new Skills. Several experimental features, such as the Rust-based React Compiler, are also available for early adopters.

Key takeaways:
- Dev server now uses up to 90% less RAM thanks to Turbopack improvements.
- Builds are faster due to disk caching, and server-side rendering can handle up to 22% more requests.
- Instant Navigations tools (e.g., Partial Prefetching, Navigation Inspector) bring SPA-like speed to Next.js apps.
- Enhanced AI agent support and new error boundary mechanisms improve developer and user experience.
