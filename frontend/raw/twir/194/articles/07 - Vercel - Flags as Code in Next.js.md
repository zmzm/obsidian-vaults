# Item 7: Vercel - Flags as Code in Next.js

Source: [https://vercel.com/blog/flags-as-code-in-next-js](https://vercel.com/blog/flags-as-code-in-next-js)

Summary:
Vercel introduces a new Flags SDK for managing feature flags in Next.js, emphasizing best practices and server-side evaluation. The SDK abstracts flag sources, supports static and dynamic evaluation, and encourages precomputing variants for performance.

Key takeaways:
- Feature flags are defined as functions, evaluated only on the server, and accept no arguments at call sites.
- The SDK enables static precomputation of variants, reducing client-side jank and layout shifts.
- Designed for easy migration between flag providers and simplified flag removal.
- Integrates with Edge Middleware for efficient routing and experimentation.
