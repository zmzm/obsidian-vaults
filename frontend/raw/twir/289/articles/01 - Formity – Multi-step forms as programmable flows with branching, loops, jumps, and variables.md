# Item 1: Formity – Multi-step forms as programmable flows with branching, loops, jumps, and variables

Source: [https://formity.app/](https://formity.app/)

Summary:
Formity is a React library designed to simplify the creation of dynamic, multi-step forms with advanced logic, such as conditional branching, loops, and jumps. It is fully type-safe, integrates with popular form libraries like React Hook Form and Formik, and is agnostic to the underlying form solution. The library provides real-world examples and a premium template (Formity Plus) for building engaging, consistent form experiences. Formity aims to be the missing layer between form libraries and complex multi-step flows, reducing boilerplate and improving maintainability.

Key takeaways:
- Enables advanced multi-step form logic (branching, loops, jumps) in React apps.
- Fully type-safe, with inferred types across steps, fields, and outputs.
- Integrates with major form libraries (React Hook Form, Formik, TanStack Form).
- Offers real-world examples and a premium template for rapid adoption.
