Summary:
Lovable has migrated new projects to use TanStack Start, a modern React framework supporting SSR, SSG, and per-route CSR with integrated server functions. This shift enables better SEO, more efficient server/client code separation, and simplified backend logic placement. The article explains the rationale for choosing TanStack Start, the benefits of its rendering model, and how Lovable’s AI adapts to new patterns for code generation and security. It also covers environment variable handling and deployment changes.

Key takeaways:
- TanStack Start provides SSR, SSG, and CSR per route, improving SEO and initial load times.
- Server functions can reside alongside components, simplifying backend logic and deployment.
- Environment variables are securely managed, with server-only secrets injected at runtime.
- Lovable’s AI is specifically trained to generate correct TanStack Start patterns, avoiding legacy or incorrect approaches.
