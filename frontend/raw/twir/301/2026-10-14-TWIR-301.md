# This Week in React #301 (MOC)

## TL;DR
- TanStack Start 1.0 is now officially stable and production-ready, after being used in production by many teams even during its beta and RC phases
- A new RFC proposes adding runtime counters to React, providing observability into component updates, renders, commits, and state changes—akin to a CPU profiler for React
- MobX introduces a new plugin to simplify React integration and improve compatibility with the React Compiler
- The Next.js ESLint config now supports both ESLint 9 and 10, addressing crashes and compatibility issues with newer Node.js and plugin versions
- Next.js will release an out-of-band security update on October 14, 2026, addressing two critical and one high-severity vulnerabilities in upstream dependencies
