# Item 8: Using Mitosis to build a Design System

Source: [https://www.voorhoede.nl/en/blog/write-components-once-run-everywhere-with-mitosis-a-beautiful-dream-or-reality/](https://www.voorhoede.nl/en/blog/write-components-once-run-everywhere-with-mitosis-a-beautiful-dream-or-reality/)

Summary:
Mitosis is an open-source tool that transforms JSX-lite components into code for multiple frameworks (React, Vue, Angular, etc.), aiming to enable "write once, run everywhere" for design systems. The author shares practical experiences, highlighting benefits like time savings and reduced need for deep framework knowledge, but also notes challenges such as strict syntax, debugging difficulties, and lack of control over generated code. Mitosis requires a mindset shift and investment in learning its conventions.

Key takeaways:
- Mitosis compiles JSX-lite to multiple frameworks, streamlining cross-framework design system development.
- Major benefits include reduced duplication and faster delivery for multi-framework support.
- Challenges include strict syntax, learning curve, debugging generated code, and incomplete documentation.
- Developers must adapt to Mitosis's constraints and tooling for success.
