# This Week in React #202 (MOC)

## TL;DR
- Josh Comeau details the technical overhaul of his blog, focusing on a modern React/Next.js stack with MDX for content, Linaria for styling, and custom code snippet theming
- A new CLI upgrade command is added to @next/codemod, allowing users to select target versions (canary, rc, latest) and automatically detect and suggest relevant codemods for migrations
- This PR migrates several Next.js dynamic APIs (cookies, headers, draftMode, searchParams, params) to async, enabling new rendering patterns and future features like partial prerendering
- A cache poisoning vulnerability was discovered in Next.js (versions 13.5.1–14.2.9) affecting non-dynamic SSR routes in the pages router, potentially allowing attackers to poison caches and serve unintended content
- This free mini-course introduces Vim/Neovim to React developers, focusing on navigation, refactoring, and productivity patterns relevant to React codebases
