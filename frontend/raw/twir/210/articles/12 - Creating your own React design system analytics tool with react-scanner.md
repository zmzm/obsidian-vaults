# Item 12: Creating your own React design system analytics tool with react-scanner

Source: [https://alexocallaghan.com/creating-your-own-react-design-system-analytics-tool](https://alexocallaghan.com/creating-your-own-react-design-system-analytics-tool)

Summary:
This post describes how to use the react-scanner package to analyze React codebases for design system component usage. By integrating react-scanner into CI pipelines, teams can generate reports on component adoption, props usage, and project metadata, enabling better tracking and strategy for design system evolution. The author details setting up a CLI and static site for data visualization.

Key takeaways:
- react-scanner enables static analysis of design system usage in React projects.
- Integration into CI provides up-to-date analytics across multiple codebases.
- Reports help guide design system adoption and maintenance strategies.
- Visualization via static site makes insights accessible to engineers and designers.
