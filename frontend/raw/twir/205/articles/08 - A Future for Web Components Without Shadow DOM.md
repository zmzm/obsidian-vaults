# Item 8: A Future for Web Components Without Shadow DOM

Source: [https://jjenzz.com/future-for-web-components-without-shadow-dom/](https://jjenzz.com/future-for-web-components-without-shadow-dom/)

Summary:
The author critiques the limitations of Shadow DOM in Web Components, especially for design systems, and explores alternatives such as Custom Elements without Shadow DOM and built-in elements. The post discusses trade-offs, including styling, accessibility, and framework integration challenges, and suggests that mixing approaches may be the most pragmatic path forward.

Key takeaways:
- Shadow DOM can hinder flexibility and styling in component libraries.
- Custom Elements without Shadow DOM offer more control but have their own caveats.
- Built-in elements and custom attributes show promise, but browser support is lacking.
- Frameworks are still needed for complex data and prop handling in Web Components.
