# Item 8: React is a programming language, and its rules are its syntax

Source: [https://buildui.com/posts/react-is-a-programming-language-and-its-rules-are-its-syntax](https://buildui.com/posts/react-is-a-programming-language-and-its-rules-are-its-syntax)

Summary:
The article argues that React imposes its own set of rules and constraints, akin to a programming language's syntax, even though it is written in JavaScript. Using the example of refs in server components, it explains why certain patterns are disallowed and how these rules help maintain UI consistency and predictability. Embracing React's constraints, rather than fighting them, leads to more productive and enjoyable development.

Key takeaways:
- React's rules (e.g., no refs in server components) are designed for consistency and reliability.
- These constraints are not enforced by JavaScript, but are essential for correct React usage.
- Understanding and embracing React's "syntax" leads to better outcomes.
- React could have been a language, but its design as a JS library requires developers to internalize its rules.
