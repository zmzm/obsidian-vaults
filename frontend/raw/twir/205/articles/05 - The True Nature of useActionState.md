# Item 5: The True Nature of useActionState

Source: [https://www.nikhilsnayak.dev/blogs/the-true-nature-of-use-action-state](https://www.nikhilsnayak.dev/blogs/the-true-nature-of-use-action-state)

Summary:
This article explores the useActionState hook introduced in React 19, clarifying its purpose for managing return values from server functions (formerly Server Actions). It explains the signature change required for server functions and demonstrates practical usage patterns, including handling TypeScript typing challenges. The post also compares useActionState with familiar client-side patterns like useReducer.

Key takeaways:
- useActionState enables client components to capture return values from server functions.
- Server function signatures change to accept prevState and formData; initial state is required.
- TypeScript integration may require extra care for complex return types.
- useActionState is framework-agnostic and works with both server and client async functions.
