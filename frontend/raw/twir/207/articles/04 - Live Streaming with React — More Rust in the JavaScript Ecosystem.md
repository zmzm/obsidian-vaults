# Item 4: Live Streaming with React — More Rust in the JavaScript Ecosystem

Source: [https://blog.swmansion.com/live-streaming-with-react-more-rust-in-the-javascript-ecosystem-f83a0371e16c](https://blog.swmansion.com/live-streaming-with-react-more-rust-in-the-javascript-ecosystem-f83a0371e16c)

Summary:
This article introduces Live Compositor, a Rust-based media server with a React-compatible JavaScript SDK for live streaming. Developers can define live stream layouts using React components, with updates sent to a Rust server for real-time rendering. The piece discusses why Rust is chosen for performance and reliability, compares alternative approaches (Chromium, FFmpeg), and highlights the flexibility of custom rendering engines with wgpu.

Key takeaways:
- Live Compositor enables live stream composition using React components, powered by a Rust backend.
- React’s abstraction allows seamless integration with non-DOM targets, leveraging react-reconciler.
- Rust is chosen for low-latency, frame-accurate rendering and portability (including WASM support).
- Custom engine offers more flexibility and performance than browser or FFmpeg-based solutions.
