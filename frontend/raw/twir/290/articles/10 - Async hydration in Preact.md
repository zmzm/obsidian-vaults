# Item 10: Async hydration in Preact

Source: [https://jovidecroock.com/blog/resumed-hydration-preact/](https://jovidecroock.com/blog/resumed-hydration-preact/)

Summary:
Preact supports resumed (async) hydration, allowing Suspense boundaries to hydrate independently and improving perceived interactivity. Hydration 2.0 in Preact 11 introduces explicit DOM boundary markers for more reliable resumed hydration, though challenges remain with consistent id generation and streaming support is being improved.

Key takeaways:
- Resumed hydration enables partial, async hydration of Suspense boundaries.
- Hydration 2.0 adds explicit boundary markers for reliability.
- Issues with useId consistency across server/client remain to be solved.
- Streaming support is being enhanced for better user experience.
