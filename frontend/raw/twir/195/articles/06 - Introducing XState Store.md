# Item 6: Introducing XState Store

Source: [https://tkdodo.eu/blog/introducing-x-state-store](https://tkdodo.eu/blog/introducing-x-state-store)

Summary:
XState Store is a new state management library by David Khourshid, blending concepts from Zustand and Redux Toolkit with an event-driven, TypeScript-friendly API. It separates state (context) from transitions (actions), offers type inference, and is framework-agnostic with React adapters. The store can be incrementally upgraded to a full state machine, providing a smooth path from simple to complex state logic.

Key takeaways:
- API combines simplicity of Zustand with Redux Toolkit's structure.
- Strong TypeScript support with inferred types from context.
- Event-driven updates via store.send, not direct setters.
- Selectors minimize unnecessary re-renders; store is framework-agnostic.
- Easy migration path to state machines as complexity grows.
