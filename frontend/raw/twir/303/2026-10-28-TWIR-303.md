# This Week in React #303 (MOC)

## TL;DR
- TanStack Redact is a lightweight browser-side replacement for React and React DOM, designed to reduce JavaScript bundle size without requiring code changes
- Next.js has announced a scheduled security release for November 3, 2026, which will address seven medium-severity vulnerabilities
- Owner migrated over 10,000 restaurant websites from a Next.js stack to Astro, achieving a 4% revenue increase per restaurant and dramatic performance improvements (e.g., LCP reduced from 5.4s to 0.7s)
- Den Odell benchmarks the performance of popular design systems (React and web component-based) on intensive UI tasks, highlighting that slow components in a design system propagate slowness to all consuming apps
- This post details a comprehensive performance optimization journey for a TanStack Start site, focusing on reducing JavaScript, optimizing font and image loading, and improving critical rendering paths
