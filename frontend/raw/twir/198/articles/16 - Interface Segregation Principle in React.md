# Item 16: Interface Segregation Principle in React

Source: [https://alexkondov.com/interface-segregation-principle-in-react/](https://alexkondov.com/interface-segregation-principle-in-react/)

Summary:
This article applies the Interface Segregation Principle (from SOLID) to React, advocating for components to depend only on the props they actually use. It highlights issues with passing large objects or unnecessary props, discusses prop drilling, and suggests alternatives like context or composition for cleaner, more maintainable code.

Key takeaways:
- Components should only receive the data they need, not entire objects.
- Reduces coupling, simplifies testing, and improves maintainability.
- Prop drilling is an anti-pattern; use context or composition instead.
- Principle leads to clearer, more robust component APIs.
