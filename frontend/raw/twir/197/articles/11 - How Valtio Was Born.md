# Item 11: How Valtio Was Born

Source: [https://blog.axlight.com/posts/how-valtio-was-born/](https://blog.axlight.com/posts/how-valtio-was-born/)

Summary:
This post recounts the motivation and design philosophy behind Valtio, a proxy-based state management library for React. It highlights the desire to support mutable state with a hooks API, the use of snapshots for React compatibility, and the focus on a minimal, JavaScript-like API. The article also notes upcoming changes for React 19 compatibility.

Key takeaways:
- Valtio enables mutable state with React hooks by leveraging proxies and snapshots.
- The API is designed to feel like plain JavaScript, avoiding method-based state access.
- Internally, Valtio separates vanilla proxy logic from React integration.
- v2 will address feedback and support React 19's new use hook.
