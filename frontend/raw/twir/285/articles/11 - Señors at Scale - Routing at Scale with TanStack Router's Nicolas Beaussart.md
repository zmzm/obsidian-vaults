Summary:
This podcast features Nicolas Beaussart discussing PayFit’s migration from React Router v5 to TanStack Router in a massive codebase, using the strangler pattern to avoid big-bang rewrites. The episode also includes interviews with Mark Erikson (Redux) and Dominik Dorfmeister (TanStack Query), focusing on open source maintenance, state management, and scaling frontend architecture.

- Lessons learned from optimizing build size and dependency management.
