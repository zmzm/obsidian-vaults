# Item 10: How to prevent re-render in React with Tailwind CSS

Source: [https://www.nico.fyi/blog/tailwind-css-group-modifier-to-prevent-react-rerender](https://www.nico.fyi/blog/tailwind-css-group-modifier-to-prevent-react-rerender)

Summary:
This article presents an alternative approach to conditionally styling React components based on scroll position using Tailwind CSS's group modifier and data attributes, instead of React state. By updating a data-scroll attribute on the body and leveraging Tailwind's group-[] syntax, components can respond to scroll events without triggering React re-renders.

Key takeaways:
- Using data attributes and Tailwind's group modifier can avoid unnecessary React re-renders.
- Scroll state is managed outside React, improving performance for global UI changes.
- Pattern is composable and can be applied across the app.
