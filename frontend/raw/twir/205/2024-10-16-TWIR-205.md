# This Week in React #205 (MOC)

## TL;DR
- Next.js 15 Release Candidate 2 introduces several new features and improvements, including an automated codemod CLI for smoother upgrades, Turbopack performance gains, breaking changes to async request APIs, enhanced server action security, and new development tools like a static route indicator
- This React core pull request partially re-lands a previous change to make prerendering always non-blocking, after addressing issues that caused a prior revert
- Next.js is proposing experimental Request Interceptors as a complement to Middleware, allowing code to run in the same process as the page or route handler, with full Node.js API access
- The popular react-beautiful-dnd library has been officially deprecated and will be archived in April 2025
- This article explores the useActionState hook introduced in React 19, clarifying its purpose for managing return values from server functions (formerly Server Actions)
