# Item 9: TanStack Start: A Mental Model for Next.js Developers

Source: [https://www.adarsha.dev/blog/tanstack-mental-model-for-nextjs-developers](https://www.adarsha.dev/blog/tanstack-mental-model-for-nextjs-developers)

Summary:
This article compares TanStack Start with Next.js, highlighting TanStack’s router-first, type-driven approach versus Next.js’s framework-first model. TanStack Start emphasizes explicit boundaries, isomorphic components, and fully typed route/search param trees, requiring explicit server-only logic via createServerFn. The mental model shift is from implicit server context to explicit, type-safe routing and data flows.

Key takeaways:
- TanStack Start is router- and type-first, with explicit server/client boundaries.
- Route trees and search params are fully typed and generated at build time.
- Data loaders are isomorphic by default; server-only logic must be explicit.
- Reduces runtime bugs and type errors compared to Next.js conventions.
