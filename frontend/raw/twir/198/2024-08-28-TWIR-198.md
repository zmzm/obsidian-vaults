# This Week in React #198 (MOC)

## TL;DR
- React Email 3.0 introduces a new component library with 54 ready-to-use email components, delivers an 11x performance boost, and adds support for React 19 RC
- This React core PR introduces the concept of "prerender" renders, which are triggered when a component suspends (e.g., during data fetching)
- This Next.js PR optimizes server action endpoints by removing unused actions from the generated manifest
- This PR enhances React DevTools to visualize Server Components within the component tree
- React Router introduces support for a `routes.ts` config file, enabling type-safe, programmatic route definitions with helper functions
