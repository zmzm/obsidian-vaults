# Item 10: HTMX Essay - You Can't Build Interactive Web Apps Except as Single Page Applications... And Other Myths

Source: [https://htmx.org/essays/you-cant/](https://htmx.org/essays/you-cant/)

Summary:
This essay challenges the notion that only SPAs (e.g., React) can deliver high-quality, interactive web apps, highlighting browser advancements like service workers and the Speculation Rules API. It explains how MPAs can achieve fast transitions and offline support with modern caching and prefetching techniques, using tools like Workbox and service workers.

Key takeaways:
- MPAs can match SPA performance with service workers and caching strategies.
- Service workers can be used outside of SPAs for asset caching and offline support.
- The Speculation Rules API enables advanced prefetching/prerendering for MPAs.
- Modern browser features reduce the performance gap between MPAs and SPAs.
