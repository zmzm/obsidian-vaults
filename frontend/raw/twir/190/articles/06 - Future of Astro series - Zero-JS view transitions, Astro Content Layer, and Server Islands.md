# Item 6: Future of Astro series - Zero-JS view transitions, Astro Content Layer, and Server Islands

Source: [https://astro.build/blog/future-of-astro-zero-js-view-transitions/](https://astro.build/blog/future-of-astro-zero-js-view-transitions/)

Summary:
Astro introduces native, zero-JavaScript view transitions using the new View Transitions API, enabling app-like page navigation without client-side JS. The feature leverages recent browser updates and replaces Astro’s previous JS-based solution, with a simple CSS at-rule for activation. Backward compatibility is maintained for browsers lacking support.

Key takeaways:
- Zero-JS view transitions are now possible in Astro via a CSS at-rule, thanks to new browser APIs.
- The change reduces client-side complexity and improves performance.
- Backward compatibility is preserved through Astro’s legacy component.
- Persistent element transitions are not yet natively supported but remain available via Astro’s component.
