# This Week in React #291 (MOC)

## TL;DR
- This article discusses how large language models (LLMs) are increasingly influencing product discovery and recommendations, and introduces the concept of Answer Engine Optimization (AEO) as a way to improve your product's visibility in LLM-generated answers
- A denial of service (DoS) vulnerability was identified in React server function packages, where specially crafted HTTP requests could exhaust server resources
- Next.js released security updates for multiple high- and medium-severity vulnerabilities affecting the App Router, Server Actions, Turbopack, and the Image Optimization API
- This pull request adds build-time generation of per-page Open Graph (OG) images for React documentation pages, so social media link previews display the specific page title (e.g., <Suspense>) instead of a generic banner
- ReactBench is a new benchmark for evaluating AI coding agents on realistic, production-grade React tasks, going beyond passing behavioral tests to include React-specific quality checks via the open-source React Doctor verifier
