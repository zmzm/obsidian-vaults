# This Week in React #294 (MOC)

## TL;DR
- Oxlint 1.79 and Oxc Transform now support the React Compiler, providing 22 new lint rules powered by the compiler’s validation passes
- This is a duplicate of Item 1, repeating the announcement of React Compiler support in Oxlint and Oxc Transform, with the same details on rules, integration, performance, and technical improvements.
- Biome is tracking remaining work for its useReactCompiler feature, focusing on test case parity with Babel and OXC, and addressing edge cases and known divergences in the Rust port
- A feature request for Bun’s bundler to support React Compiler, noting its recent v1.0 release and the impact on React development patterns
- A React pull request flips the enableParallelTransitions feature flag on by default in the open-source and canary builds, as well as all hardcoded forks (including React Native)
