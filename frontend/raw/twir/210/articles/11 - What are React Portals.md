# Item 11: What are React Portals?

Source: [https://techhub.iodigital.com/articles/what-are-react-portals](https://techhub.iodigital.com/articles/what-are-react-portals)

Summary:
React Portals allow components to render outside their parent DOM hierarchy, solving common UI challenges like managing overlays, modals, and notifications. The article explains how to use createPortal, provides practical examples, and discusses benefits such as improved CSS control, accessibility, and event handling. Portals are especially useful for integrating React with third-party or legacy codebases.

Key takeaways:
- Portals render components outside their parent DOM node.
- Useful for modals, tooltips, notifications, and overlays.
- Improve CSS management, accessibility, and event handling.
- Maintain React's virtual DOM hierarchy while altering actual DOM placement.
