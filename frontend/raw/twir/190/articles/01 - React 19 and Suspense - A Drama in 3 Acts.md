# Item 1: React 19 and Suspense - A Drama in 3 Acts

Source: [https://tkdodo.eu/blog/react-19-and-suspense-a-drama-in-3-acts](https://tkdodo.eu/blog/react-19-and-suspense-a-drama-in-3-acts)

Summary:
This article provides a detailed, chronological breakdown of the recent controversy around React 19’s Suspense behavior change. Initially, React 19 RC introduced many anticipated features, but a shift in Suspense’s handling of sibling components caused unexpected data-fetching waterfalls instead of parallel requests. The author explains the technical background, community reaction, and rationale behind the change, highlighting the trade-offs and the community’s pushback.

Key takeaways:
- React 19 RC brought many improvements, including new hooks, the use operator, server actions, and an experimental compiler.
- A significant change: Suspense boundaries now process sibling components sequentially, causing data-fetching waterfalls.
- This change was intended as a performance optimization but breaks common patterns and negatively impacts perceived performance.
- The community quickly noticed, discussed, and challenged the change, prompting further debate on React’s direction.
