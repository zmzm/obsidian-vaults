# Item 4: Next.js Security Release and Our Next Patch Release

Source: [https://nextjs.org/blog/next-security-release-program](https://nextjs.org/blog/next-security-release-program)

Summary:
Next.js is formalizing its security release process, moving from ad-hoc patches to a predictable, scheduled release cadence. The first scheduled security release is set for July 20, 2026, covering multiple high and medium severity vulnerabilities in Next.js 16.2 and 15.5. The announcement also details their security program, bug bounty, and how urgent issues will still be handled promptly.

Key takeaways:
- Scheduled monthly security releases for predictability and planning.
- First release targets July 20, 2026, with patches for major versions.
- Ongoing commitment to rapid response for urgent vulnerabilities.
- Collaboration with researchers and expanded bug bounty program.
