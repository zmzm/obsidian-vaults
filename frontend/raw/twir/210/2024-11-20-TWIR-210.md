## TL;DR
- A recent change in React 19 disables prerendering of sibling components when a component suspends, leading to performance regressions in common data-fetching patterns
- Next.js is introducing an experimental client Segment Cache, which caches data per route segment rather than per full URL
- A proposed change in React Query moves staleTime from the observer level to the query level, enforcing a single staleTime per query key
