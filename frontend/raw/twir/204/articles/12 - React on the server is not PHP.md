# Item 12: React on the server is not PHP

Source: [https://www.artmann.co/articles/react-on-the-server-is-not-php](https://www.artmann.co/articles/react-on-the-server-is-not-php)

Summary:
This opinion piece argues that modern server-side React (with frameworks like Next.js and Remix) is fundamentally different from traditional PHP-based server rendering. While both approaches render HTML on the server, modern frameworks offer unified tooling, declarative UIs, and blur the frontend/backend divide, enabling full-stack development with better maintainability and user experience. The author emphasizes that these advances build on lessons from the past, not a return to it.

Key takeaways:
- Modern server-side React leverages unified JS tooling, declarative components, and state-driven UIs.
- Full-stack JS frameworks close the gap between frontend and backend, enabling more cohesive products.
- The approach is more maintainable and scalable than old PHP/imperative JS patterns.
- The shift enables developers to own end-to-end features and optimize both client and server logic.
