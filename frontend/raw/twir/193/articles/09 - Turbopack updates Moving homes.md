# Item 9: Turbopack updates: Moving homes

Source: [https://vercel.com/blog/turbopack-moving-homes](https://vercel.com/blog/turbopack-moving-homes)

Summary:
Vercel is moving the Turbopack bundler’s source code into the Next.js monorepo to streamline development and improve integration. Turbopack is already passing the full Next.js development test suite and is being used in production at Vercel, with ongoing work to stabilize production builds and optimize performance. The move will not affect Turborepo, and Turbopack remains framework-agnostic, with a focus on Next.js in the near term.

Key takeaways:
- Turbopack’s codebase will be co-located with Next.js for faster iteration and easier maintenance.
- The bundler is stable for development and is being actively improved for production readiness.
- Turbopack is not becoming Next.js-only; broader framework support is still planned.
- No changes for users of Turborepo or existing Turbopack workflows.
