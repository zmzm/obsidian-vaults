# System Prompt

System prompt задаёт роль, постоянные правила и границы поведения модели. Текущая задача обычно должна оставаться в user prompt.

## System vs User

System prompt:

- роль модели
- глобальные правила
- политика источников
- требования к честности и отказу от выдумывания
- правила работы с контекстом

User prompt:

- конкретная задача
- текущий вопрос
- одноразовые параметры
- данные для конкретного запроса

## Useful Rules

- не выдумывать факты
- явно говорить, если данных недостаточно
- ссылаться на предоставленный контекст
- не использовать внешние знания, если задача требует опоры только на документы
- сохранять заданный формат ответа

## Why It Matters

Роль и глобальные правила работают лучше, когда они отделены от текущей задачи. Это особенно важно для [[RAG]] и [[Agents]], где один и тот же ассистент должен стабильно следовать правилам на разных запросах.
