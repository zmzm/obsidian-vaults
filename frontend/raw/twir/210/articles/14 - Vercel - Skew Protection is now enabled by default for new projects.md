# Item 14: Vercel - Skew Protection is now enabled by default for new projects

Source: [https://vercel.com/changelog/skew-protection-is-now-enabled-by-default-for-new-projects](https://vercel.com/changelog/skew-protection-is-now-enabled-by-default-for-new-projects)

Summary:
Vercel has enabled Skew Protection by default for all new projects, ensuring that client and server code versions remain in sync during deployments. This feature helps prevent version mismatch errors, especially during rapid deployments or when using server actions. Existing projects can opt-in manually.

Key takeaways:
- Skew Protection prevents client/server version mismatches on Vercel.
- Enabled by default for new projects; manual opt-in for existing ones.
- Reduces errors from hashed bundle changes and deployment timing.
