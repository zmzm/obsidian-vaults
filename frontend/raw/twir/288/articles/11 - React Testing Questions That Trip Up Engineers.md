# Item 11: React Testing Questions That Trip Up Engineers

Source: [https://howtotestfrontend.com/resources/react-testing-interview-questions](https://howtotestfrontend.com/resources/react-testing-interview-questions)

Summary:
This post highlights common pitfalls in React testing, especially tests that never fail due to poor assertions, over-mocking, or testing static content. It provides examples of anti-patterns and suggests better approaches, such as asserting both presence and absence and avoiding tests that cannot break.

Key takeaways:
- Tests that never fail are often due to poor test design or over-mocking.
- Asserting static content or always-truthy conditions adds no value.
- Use conditional assertions and test both positive and negative cases for robustness.
- Overuse of mocks can make tests meaningless; focus on real behavior.
