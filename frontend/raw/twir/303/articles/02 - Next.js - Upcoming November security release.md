# Item 2: Next.js - Upcoming November security release

Source: [https://nextjs.org/blog/upcoming-nextjs-security-release-november-2026](https://nextjs.org/blog/upcoming-nextjs-security-release-november-2026)

Summary:
Next.js has announced a scheduled security release for November 3, 2026, which will address seven medium-severity vulnerabilities. Full advisories, affected versions, and upgrade instructions will be published alongside the release. Teams are encouraged to plan upgrades in advance and can participate in Vercel’s open source security program.

Key takeaways:
- Security release scheduled for November 3, 2026, addressing multiple vulnerabilities.
- Full details and upgrade instructions will be available at release.
- Vercel runs an open source bug bounty program for security contributions.

## Our security program
We work with security researchers to secure Next.js and other open source frameworks through [Vercel's Open Source Bug Bounty](https://hackerone.com/vercel). Anyone interested in contributing to the security of eligible frameworks is encouraged to participate there.
Any questions or concerns regarding our security programs or vulnerability management can be sent to [security@vercel.com](mailto:security@vercel.com).
