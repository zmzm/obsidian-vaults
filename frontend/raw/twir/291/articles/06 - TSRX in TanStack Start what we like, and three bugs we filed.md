# Item 6: TSRX in TanStack Start: what we like, and three bugs we filed

Source: [https://www.jxd.dev/blog/tsrx-tanstack-start](https://www.jxd.dev/blog/tsrx-tanstack-start)

Summary:
The post reviews integrating TSRX—a JSX successor focused on co-located structure and AI-native codebases—into TanStack Start projects. TSRX allows for statement-based control flow (if, for, switch, try) inside templates, scoped styles, and colocated logic, all compiling down to standard React components. The author demonstrates how TSRX simplifies component structure and styling compared to conventional JSX, and notes some SSR integration bugs found during testing.

Key takeaways:
- TSRX enables more expressive, maintainable component code by allowing real control flow and colocated styles.
- It compiles to React, so runtime semantics remain unchanged.
- The integration with TanStack Start is smooth on the client, but SSR has some rough edges (bugs reported upstream).
