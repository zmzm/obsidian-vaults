# Item 9: From React to native web with nanotags: a migration that saved 100 KB

Source: [https://evilmartians.com/chronicles/from-react-to-native-web-with-nanotags-a-migration-that-saved-100kb](https://evilmartians.com/chronicles/from-react-to-native-web-with-nanotags-a-migration-that-saved-100kb)

Summary:
A case study of migrating a marketing site from React to native Web Components using a small library called nanotags, resulting in a 100 KB reduction in JavaScript bundle size. The author discusses why React is often overkill for static-first sites, the benefits and challenges of using Web Components, and how Astro’s architecture enables a minimal, framework-free approach. The migration was straightforward due to limited interactivity needs, and the resulting site was faster and more accessible.

Key takeaways:
- React’s SPA model is often unnecessary for static marketing sites; most interactivity can be handled natively.
- Web Components (Custom Elements) offer a stable, framework-free component model with minimal bundle overhead.
- Astro enables zero-JS by default and makes it easy to hydrate only interactive components.
- Migration to Web Components was easier than expected, with significant performance and accessibility gains.
