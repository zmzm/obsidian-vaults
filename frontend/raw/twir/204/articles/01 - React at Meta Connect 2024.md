# Item 1: React at Meta Connect 2024

Source: [https://engineering.fb.com/2024/10/02/android/react-at-meta-connect-2024/](https://engineering.fb.com/2024/10/02/android/react-at-meta-connect-2024/)

Summary:
Meta showcased how React and React Native are central to their product development, powering apps like Instagram, Facebook, and Meta Horizon for Meta Quest and other platforms. The article details technical decisions, code sharing strategies, performance optimizations, and cross-platform infrastructure, including the use of bleeding-edge React features and internal tooling. Teams leveraged React Native for rapid iteration, high-quality animations, and platform-specific experiences, while code sharing (via StyleX, React Strict DOM, and internal routers) accelerated feature delivery and consistency. The Meta Spatial Editor, built with React Native for Desktop, demonstrates React's reach beyond mobile/web, with native integrations and improved developer experience even for C++-focused engineers.

Key takeaways:
- React and React Native are foundational at Meta, enabling rapid, high-quality development across web, mobile, MR, and desktop.
- Code sharing (StyleX, React Strict DOM, internal routers) reduces duplication and accelerates feature parity across platforms.
- Performance tuning (e.g., earlier network fetches with Relay) and profiling tools (React DevTools, Systrace) are critical for app quality.
- React Native for Desktop enables native integrations and high-performance UIs, even for teams with non-JS backgrounds.
