# Item 9: Increasing Vite's potential with the Environment API

Source: [https://green.sapphi.red/blog/increasing-vites-potential-with-the-environment-api](https://green.sapphi.red/blog/increasing-vites-potential-with-the-environment-api)

Summary:
Vite v6 introduces the Environment API, allowing its code execution layer ("Module Runner") to be swapped and extended for different runtimes (Deno, Bun, Edge, etc.), not just Node.js. This enables support for multiple bundles and environments (browser, SSR, middleware, edge, etc.) in a single project, unlocking new deployment and development patterns. The API is experimental but aims to make Vite more flexible and future-proof for evolving JavaScript ecosystems.

Key takeaways:
- Environment API decouples code transformation and execution, supporting multiple runtimes and bundles.
- Enables advanced scenarios (e.g., running parts of an app on Node.js, Edge, service workers, etc.).
- Facilitates smoother upgrades and compatibility for Vite-based projects.
- The feature is experimental; feedback and ecosystem testing are encouraged.
