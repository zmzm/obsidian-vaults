# Item 5: ReactBench - Evaluates frontier coding agents on production React work

Source: [https://www.reactbench.com/blog](https://www.reactbench.com/blog)

Summary:
ReactBench is a new benchmark for evaluating AI coding agents on realistic, production-grade React tasks, going beyond passing behavioral tests to include React-specific quality checks via the open-source React Doctor verifier. The benchmark covers both feature implementation and code improvement tasks, measuring not just correctness but also performance, accessibility, and maintainability. Results show that even top models struggle with real-world React work, often introducing subtle bugs or accessibility issues.

Key takeaways:
- ReactBench uses real open-source codebases and tasks, not synthetic puzzles.
- Solutions must pass both behavioral tests and 400+ React Doctor rules.
- Leading AI models solve fewer than half of benchmark tasks; most new issues are bugs or accessibility violations.
- The benchmark highlights the gap between passing tests and shipping robust React code.
