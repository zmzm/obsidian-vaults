# This Week in React #290 (MOC)

## TL;DR
- SVAR React Gantt is a high-performance, native React component for rendering interactive Gantt charts, supporting timelines and task/dependency management
- The React team has been reorganized into working groups, each focusing on a specific area such as Server, DOM, Fiber, Docs & Community, Compiler, DevX, and React Native
- This documentation explains when and how a <Suspense> boundary is activated in React, detailing its use cases, props, and caveats
- Next.js is formalizing its security release process, moving from ad-hoc patches to a predictable, scheduled release cadence
- Better Auth, an open-source, framework-agnostic authentication solution, is joining Vercel to accelerate its mission and scale its impact
