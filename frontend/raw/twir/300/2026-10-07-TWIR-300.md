# This Week in React #300 (MOC)

## TL;DR
- Next.js 16.4 introduces significant improvements, most notably making Cache Components the recommended default for all new and existing apps
- The React Foundation Contributors Summit is scheduled for November 10–12, 2026, at Meta King's Cross in London
- React Conf Ghana is a two-day conference on November 4–5, 2026, at the University of Ghana, bringing together engineers, designers, and community members
- A new Next.js pull request introduces the unstable_paramMatching and unstable_generateParamMatching APIs, allowing parameter matching to be configured separately from build-time prerenders in Cache Components apps
- A critical security vulnerability (CVE-2026-102989) affecting TanStack Start's server-function response handling has been patched
