# Item 8: Rethinking TSRX

Source: [https://tsrx.dev/blog/rethinking-tsrx](https://tsrx.dev/blog/rethinking-tsrx)

Summary:
TSRX, a JSX-inspired template language, is evolving to be more JSX-like and expression-based, reducing friction and confusion for developers and LLMs. The update removes the need for quoted static text, clarifies boundaries between template and JavaScript logic, and introduces JSX statement containers (@{...}) for embedding statements before template output. Comments and fragments are handled in familiar JSX ways, improving readability and compatibility.

Key takeaways:
- TSRX now closely mirrors JSX, making static text and dynamic values intuitive.
- Statement containers (@{...}) allow setup logic before template output.
- Comments and fragments work as in standard JSX.
- Reduces ambiguity for both humans and AI-assisted tooling.
