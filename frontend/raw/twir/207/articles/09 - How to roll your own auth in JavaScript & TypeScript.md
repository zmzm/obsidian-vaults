# Item 9: How to roll your own auth in JavaScript & TypeScript

Source: [https://www.robinwieruch.de/how-to-roll-your-own-auth/](https://www.robinwieruch.de/how-to-roll-your-own-auth/)

Summary:
This tutorial walks through building a session-based authentication system in JavaScript/TypeScript, focusing on backend control and security. It covers database schema design, secure session token generation, password hashing, and session validation, using Oslo.js for cryptography and encoding. The approach is framework-agnostic and emphasizes understanding authentication fundamentals.

Key takeaways:
- Rolling your own auth increases flexibility and understanding of security principles.
- Sessions are stored in the database, with hashed tokens and expiration logic.
- Oslo.js provides cryptographic utilities for secure token handling.
- The solution is backend-agnostic and can be adapted to Express.js, Next.js, etc.
