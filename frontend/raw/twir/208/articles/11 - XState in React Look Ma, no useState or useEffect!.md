# Item 11: XState in React: Look Ma, no useState or useEffect!

Source: [https://www.frontendundefined.com/posts/monthly/xstate-in-react/](https://www.frontendundefined.com/posts/monthly/xstate-in-react/)

Summary:
The post advocates for using XState, a state machine library, in React apps instead of traditional useState/useEffect hooks, especially for complex or highly interactive components. It explains the concepts of state machines and state charts, provides code samples for integrating XState with React, and demonstrates how this approach leads to more maintainable, predictable state management.

Key takeaways:
- XState models state transitions explicitly, reducing bugs in complex UIs.
- React integration is achieved via hooks like useActor and useSelector.
- State machines are especially useful for components with multiple visual or behavioral states.
- The approach improves maintainability and clarity over ad-hoc hook usage.
