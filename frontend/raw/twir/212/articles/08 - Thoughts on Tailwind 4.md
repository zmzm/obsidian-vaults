# Item 8: Thoughts on Tailwind 4

Source: [https://nmn.sh/blog/2024-11-30-thoughts-on-tailwind-4](https://nmn.sh/blog/2024-11-30-thoughts-on-tailwind-4)

Summary:
This opinion piece reviews the Tailwind CSS v4.0 beta, highlighting both positive changes (LightningCSS integration, CSS-first config, cascade layers, simplified theme config) and concerns (performance pitfalls with CSS variables, new descendant/variant features that may undermine atomic CSS principles). The author warns that some new features could encourage bad practices or increase CSS bloat, but acknowledges many improvements and ongoing support for existing workflows.

Key takeaways:
- LightningCSS integration and cascade layers are major wins for performance and maintainability.
- CSS-first configuration and new variants offer flexibility but may reduce type safety and atomicity.
- Descendant selectors and certain variants could lead to “styling at a distance” and potential CSS bloat.
- Most changes are positive, but caution is advised when adopting new features that break atomic CSS conventions.
