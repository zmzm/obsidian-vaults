# Item 1: Shadcn introduces a new CLI

Source: [https://ui.shadcn.com/docs/changelog](https://ui.shadcn.com/docs/changelog)

Summary:
Shadcn UI has added new CLI commands for working with UI presets, making it easier to decode, resolve, share, and open preset configurations. The CLI supports inspecting preset codes, resolving presets from existing projects (including monorepos), and generating shareable URLs for presets. This streamlines collaboration and handoff, especially when working with coding agents or teams. The update aims to reduce manual steps in preset management and sharing.

Key takeaways:
- New CLI commands: decode, resolve, url, open for presets.
- Works with monorepos and various package managers.
- Enables easy inspection, sharing, and customization of UI presets.
- Reduces manual effort in managing and handing off preset configurations.
