# Item 7: What the heck is atomic state management?

Source: [https://www.frontendundefined.com/posts/monthly/jotai-atomic-state-management/](https://www.frontendundefined.com/posts/monthly/jotai-atomic-state-management/)

Summary:
This article introduces atomic state management in React, focusing on Jotai as the leading library in this space. It explains the concept of atoms (small state containers), derived atoms, and how they compare to useState and context. The post includes practical code examples and discusses the pros and cons of adopting Jotai in real-world projects.

Key takeaways:
- Atomic state management splits state into small, composable atoms.
- Jotai offers a simple API and supports derived atoms for computed state.
- Atoms can be read, written, and composed, offering more flexibility than context.
- Jotai is now more mature and widely adopted than Recoil.
