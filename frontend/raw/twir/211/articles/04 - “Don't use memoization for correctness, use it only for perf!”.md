# Item 4: “Don't use memoization for correctness, use it only for perf!”

Source: [https://bsky.app/profile/gsathya.bsky.social/post/3lbk5putwkc2d](https://bsky.app/profile/gsathya.bsky.social/post/3lbk5putwkc2d)

Summary:
A succinct reminder from Sathya: memoization in React should only be used for performance optimization, not for ensuring correctness of code or logic. Using memoization for correctness can lead to subtle bugs and maintenance issues.

Key takeaways:
- Memoization is a performance tool, not a correctness guarantee.
- Relying on memoization for correctness is an anti-pattern.
- Keep memoization usage focused and intentional.
