# Item 10: React Form with Loading State (Pending Action)

Source: [https://www.robinwieruch.de/react-form-loading-pending-action/](https://www.robinwieruch.de/react-form-loading-pending-action/)

Summary:
This tutorial demonstrates three ways to show a loading spinner in React forms during pending actions: using useActionState, useFormStatus, and their combination. It explains how to manage pending state for form submissions, with practical code samples for each approach.

Key takeaways:
- useActionState attaches state to actions and provides a pending state for forms.
- useFormStatus gives access to the pending state in a child component of the form.
- Both hooks can be combined for advanced scenarios (e.g., error handling).
- Proper use of these hooks prevents double submissions and improves UX.
