# Item 10: The use cache Directive Deep Dive in Next.js

Source: [https://www.nextjscourse.dev/courses/nextjs-course/use-cache-deep-dive](https://www.nextjscourse.dev/courses/nextjs-course/use-cache-deep-dive)

Summary:
Next.js introduces the use cache directive, allowing granular caching of functions, components, and routes—beyond the previous unstable_cache. It supports multiple caching levels, cache profiles, tagging, and manual invalidation, and is designed for use with React Server Components. The feature is experimental and requires enabling a flag in Next.js.

Key takeaways:
- use cache enables fine-grained caching for serializable data, components, and routes.
- Supports cache profiles (duration), tags (for selective invalidation), and manual revalidation.
- Route-level caching is possible by adding the directive at the top of a file.
- Experimental—keep up with Next.js docs for changes.
