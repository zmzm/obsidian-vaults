# Item 14: Conditional Props in React Using Type Discrimination

Source: [https://elanmed.dev/blog/conditional-props-using-type-discrimination](https://elanmed.dev/blog/conditional-props-using-type-discrimination)

Summary:
This post explores how to enforce conditional prop requirements in React components using TypeScript, based on the value of another prop. It examines generic-based solutions and their limitations, then discusses more robust approaches using discriminated unions and type guards. The goal is to ensure at compile time that the correct props are provided for each variant, improving type safety and developer experience.

Key takeaways:
- Generics can express conditional props but have limitations with type narrowing.
- Discriminated unions and type guards provide better compile-time safety.
- Proper typing prevents invalid prop combinations and enforces required props based on other prop values.
- The pattern is applicable to both React components and plain functions.
