# Item 6: Storybook Test sneak peek

Source: [https://storybook.js.org/blog/storybook-test-sneak-peek/](https://storybook.js.org/blog/storybook-test-sneak-peek/)

Summary:
Storybook is introducing Storybook Test, a new tool for fast, browser-based, flake-free UI testing that integrates component, visual, and accessibility tests directly into the Storybook UI. The tool leverages Vitest for component tests, Chromatic for visual tests, and Axe for accessibility, with tight VSCode integration and a focus on developer experience. The post outlines the motivation, features, and early access program, aiming to address common pain points in frontend testing.

Key takeaways:
- Storybook Test runs component, visual, and a11y tests simultaneously in the browser, reducing flakiness and improving speed.
- Test results are visualized inside Storybook, enabling click-to-debug workflows.
- Integrates with Vitest, Chromatic, and Axe; supports VSCode.
- Early access program is available for teams using Storybook.
