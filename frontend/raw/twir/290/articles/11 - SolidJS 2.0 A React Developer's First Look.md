# Item 11: SolidJS 2.0: A React Developer's First Look

Source: [https://morello.dev/blog/solidjs-2-react-developers-first-look](https://morello.dev/blog/solidjs-2-react-developers-first-look)

Summary:
SolidJS 2.0 introduces native async support and a refined reactivity model that differs fundamentally from React's component re-execution and virtual DOM diffing. State updates flow directly to affected DOM nodes, and async computations and mutations are handled natively in the reactive graph, with new primitives for optimistic updates and batching.

Key takeaways:
- Fine-grained reactivity: components run once, updates are direct.
- Async data and mutations are first-class, with <Loading> and action primitives.
- Batching is deterministic and requires explicit flush for immediate reads.
- API changes and improved ergonomics for React developers.
