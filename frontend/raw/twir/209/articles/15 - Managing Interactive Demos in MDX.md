# Item 15: Managing Interactive Demos in MDX

Source: [https://abhisaha.com/blog/managing-interactive-demos-mdx](https://abhisaha.com/blog/managing-interactive-demos-mdx)

Summary:
The author describes the challenges of managing interactive demos with controls in MDX-based articles, particularly when using Astro and React. They outline desired patterns for embedding demos and controls, discuss limitations of render props in Astro MDX, and present a solution using custom hooks and reusable layout components. The approach balances MDX content clarity with demo interactivity and maintainability.

Key takeaways:
- Embedding interactive demos in MDX can be challenging due to static rendering and slot limitations (in Astro).
- Render props may not work as expected in Astro MDX; alternative patterns are needed.
- Custom hooks and reusable layout components (Row, Column) help manage controls and demo state.
- The solution keeps article content clean and demos maintainable.
