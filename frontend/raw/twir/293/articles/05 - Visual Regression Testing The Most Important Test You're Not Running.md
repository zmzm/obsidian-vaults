# Item 5: Visual Regression Testing: The Most Important Test You're Not Running

Source: [https://howtotestfrontend.com/resources/visual-regression-testing-introduction-guide](https://howtotestfrontend.com/resources/visual-regression-testing-introduction-guide)

Summary:
Visual regression testing captures screenshots of your app or components and compares them to a baseline to catch unintended visual changes. Unlike unit or E2E tests, it validates actual appearance, catching layout, CSS, and responsive issues that functional tests miss. Tools like Percy, Chromatic, and Vitest Browser Mode integrate with CI/CD pipelines to automate visual checks and approvals. The article emphasizes the growing importance of visual testing, especially with AI-generated code changes.

Key takeaways:
- Visual regression tests catch UI appearance regressions that functional tests cannot.
- Integrates with CI/CD and E2E tools (e.g., Playwright, Cypress, Storybook/Chromatic, Percy).
- Essential for detecting subtle or widespread visual bugs, especially in component libraries or large apps.
- Particularly valuable as AI-generated code increases the risk of unnoticed UI changes.
