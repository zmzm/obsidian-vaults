# This Week in React #299 (MOC)

## TL;DR
- Panda CSS 2.0 introduces a complete rewrite of its compiler, moving from a TypeScript/Node-based engine to a Rust-based one built on Oxc
- Panda CSS now supports true zero-runtime CSS-in-JS by transforming style function calls (like css(), patterns, and recipes) into static class strings at build time via bundler plugins
- Panda Studio is a web tool that visualizes your design-system.json, showing resolved tokens (colors, spacing, fonts, etc.) and now tracks which tokens are actually used in your codebase
- Next.js released security updates addressing several vulnerabilities, including a high-severity SSRF in image optimization and multiple medium-severity cache and information disclosure issues
- GitHub’s Primer Design System migrated from a CSS-in-JS solution to CSS Modules to improve performance and maintainability
