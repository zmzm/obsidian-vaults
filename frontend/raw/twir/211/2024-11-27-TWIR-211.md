# This Week in React #211 (MOC)

## TL;DR
- React Router v7 has been released, bringing many features from Remix back into the core router
- A longstanding React issue is that reordering stateful nodes can cause state loss
- Next.js introduces an experimental inlineCSS flag for the App Router, which inlines CSS as <style> tags instead of generating <link> tags
- A succinct reminder from Sathya: memoization in React should only be used for performance optimization, not for ensuring correctness of code or logic
- TanStack Start, a new full-stack framework, initially considered writing adapters for each hosting platform but found this approach unsustainable
