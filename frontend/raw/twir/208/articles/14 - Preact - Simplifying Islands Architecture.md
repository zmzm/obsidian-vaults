# Item 14: Preact - Simplifying Islands Architecture

Source: [https://preactjs.com/blog/simplifying-islands-arch/](https://preactjs.com/blog/simplifying-islands-arch/)

Summary:
This guide explains the "islands architecture" pattern for SSR+hydration apps, using Preact as an example. It covers initial server rendering, partial hydration of interactive components, and bundling strategies for efficient delivery. The article provides code samples and discusses manifest-based script injection for production builds.

Key takeaways:
- Islands architecture enables selective hydration of interactive components for performance.
- Preact’s render/hydrate methods facilitate SSR and client-side interactivity.
- Bundling and manifest management are important for production deployments.
- The approach is applicable to other frameworks, not just Preact.
