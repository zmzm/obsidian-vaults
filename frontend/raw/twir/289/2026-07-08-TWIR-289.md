# This Week in React #289 (MOC)

## TL;DR
- Formity is a React library designed to simplify the creation of dynamic, multi-step forms with advanced logic, such as conditional branching, loops, and jumps
- This RFC proposes adding first-class WebSocket support to Next.js App Router Route Handlers via a new NextResponse.upgrade() API
- This article reverse-engineers the architecture of ChatGPT Web, focusing on its evolution from Next.js (Pages Router) to Remix, and finally to React Router 7 in framework mode
- The author describes enabling the React Compiler (v1.0) in a production Next.js codebase to automate memoization, replacing useMemo and useCallback
- This post explains how hydration mismatches in React apps—when server-rendered and client-rendered DOM differ—can severely impact performance, particularly Largest Contentful Paint (LCP)
