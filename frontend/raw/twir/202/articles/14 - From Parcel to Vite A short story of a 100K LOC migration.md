# Item 14: From Parcel to Vite: A short story of a 100K LOC migration

Source: [https://blog.logto.io/parcel-to-vite](https://blog.logto.io/parcel-to-vite)

Summary:
This migration story details moving a large TypeScript/React/SASS codebase from Parcel to Vite, citing Parcel’s stagnation and Vite’s superior ecosystem and performance. The post covers Vite’s out-of-the-box support for monorepos, TypeScript, React, SASS, MDX, and SVGs, as well as configuration tips for path aliases, fast refresh, lazy loading, and asset compression.

Key takeaways:
- Vite offers better support, ecosystem, and performance than Parcel for large React projects.
- Migration is straightforward, with plugins for MDX, SVG, SASS, and more.
- Discusses configuration for path aliases, fast refresh, and chunking.
- Highlights real-world migration pain points and solutions.
