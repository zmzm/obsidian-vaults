# Item 1: How I Built My Blog

Source: [https://www.joshwcomeau.com/blog/how-i-built-my-blog-v2/](https://www.joshwcomeau.com/blog/how-i-built-my-blog-v2/)

Summary:
Josh Comeau details the technical overhaul of his blog, focusing on a modern React/Next.js stack with MDX for content, Linaria for styling, and custom code snippet theming. The post discusses the rationale behind technology choices, challenges with styling and CSS bundling in Next.js, and the benefits of MDX for interactive content. He also shares lessons learned, including issues with Linaria and future interest in Pigment CSS. The article is a comprehensive resource for anyone considering a similar tech stack or migration.

Key takeaways:
- Uses Next.js 15 (beta), React 19 (beta), MDX, Linaria, and other modern tools.
- MDX enables interactive, React-powered blog content with a better authoring experience than pure React or Markdown.
- Linaria offers zero-runtime CSS-in-JS but has compatibility and bundling issues with Next.js; Pigment CSS is a promising alternative.
- Custom Shiki-powered code snippets improve code presentation and are compatible with React Server Components.
