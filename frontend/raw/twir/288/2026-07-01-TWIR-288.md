# This Week in React #288 (MOC)

## TL;DR
- Next.js 16.3 introduces "Instant Navigations," a set of tools that make server-driven Next.js apps feel as responsive as client-side SPAs
- Dan Abramov, a well-known React core team member, has joined the Next.js team at Vercel in a part-time capacity
- Next.js 16.3 expands its AI-driven development tooling, targeting agent-based workflows and actionable error handling
- Turbopack in Next.js 16.3 delivers major performance improvements, including drastic reductions in dev server memory usage (up to 90%), persistent file system caching for both dev and build, and experimental support for the Rust-based React Compiler
- The use() API in React allows reading the value of a Promise or context, supporting both synchronous and asynchronous data access
