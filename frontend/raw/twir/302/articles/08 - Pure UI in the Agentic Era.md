# Item 8: Pure UI in the Agentic Era

Source: [https://mattrothenberg.com/notes/pure-ui-agentic-era/](https://mattrothenberg.com/notes/pure-ui-agentic-era/)

Summary:
This essay revisits the "Pure UI" principle—UI as a pure function of state—in the context of agent-generated code and complex application states. It argues that making display-relevant state explicit and rendering all meaningful UI states (e.g., via Storybook or visual grids) is essential for both human and agent developers. The author highlights the risks of implicit state, incomplete test coverage, and the importance of visualizing all relevant combinations before merging changes.

Key takeaways:
- Pure UI (ui = fn(state)) is crucial for confidence in agent- or human-generated UIs.
- Real-world state is often scattered; making it explicit aids testing and review.
- Rendering all relevant states (e.g., with Storybook, Playwright) exposes edge cases and bugs.
- Encourages teams to document and visualize all meaningful UI states, not just the "happy path".
