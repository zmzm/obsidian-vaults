# This Week in React #286 (MOC)

## TL;DR
- Oxlint 1.70 introduces an experimental lint rule that runs the React Compiler's analysis in lint-only mode, surfacing violations of the Rules of React (e.g., conditional hooks, reading refs during render, mutating props/state)
- This PR exposes Oxc’s experimental React Compiler to Rolldown’s transform option layers, allowing React/Vite users to opt into compiler memoization
- SWC adds experimental support for the Rust React Compiler, bridging SWC and React Compiler ASTs/scopes and exposing configuration via .swcrc (jsc.transform.reactCompiler)
- Rspack updates its SWC toolchain to support React Compiler configuration via builtin:swc-loader, making this the primary documented setup for React Compiler usage
- Next.js introduces an experimental.rustReactCompiler config option to enable the Rust-based React Compiler in Turbopack builds
