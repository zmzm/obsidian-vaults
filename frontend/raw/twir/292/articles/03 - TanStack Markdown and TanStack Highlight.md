# Item 3: TanStack Markdown and TanStack Highlight

Source: [https://tanstack.com/blog/introducing-tanstack-markdown-and-highlight](https://tanstack.com/blog/introducing-tanstack-markdown-and-highlight)

Summary:
TanStack introduces two new libraries: TanStack Markdown for parsing Markdown into a serializable AST, and TanStack Highlight for lightweight syntax highlighting. Both are designed to be small, framework-agnostic, and focused on technical documentation needs, avoiding the bloat of full-featured editors or plugin-heavy pipelines. The libraries separate parsing and highlighting, support streaming, and are highly modular with minimal dependencies.

Key takeaways:
- TanStack Markdown parses Markdown into plain data structures, enabling flexible rendering and caching.
- TanStack Highlight provides deterministic, compact HTML highlighting for known languages, with a tiny footprint.
- Both libraries are decoupled, allowing independent use and explicit integration.
- Designed for technical docs, blogs, and AI streaming output, with React and Octane adapters as optional peers.
