# Item 8: Generate a PDF in React

Source: [https://spacejelly.dev/posts/generate-a-pdf-from-html-in-javascript](https://spacejelly.dev/posts/generate-a-pdf-from-html-in-javascript)

Summary:
This article compares several approaches to generating PDFs from React apps, including html2pdf.js (DOM-to-PDF in-browser), React PDF (component-based, server-compatible), and Puppeteer (browser automation for PDF generation). It discusses trade-offs in rendering fidelity, accessibility, and integration with React and Next.js.

Key takeaways:
- html2pdf.js is browser-based and easy to use but may have rendering quirks.
- React PDF offers a React-like API and works well for dynamic, server-side PDF generation; however, it may lack React 19 support.
- Puppeteer enables high-fidelity PDF creation via browser automation, suitable for server-side workflows.
- Choice depends on environment, fidelity needs, and integration requirements.
