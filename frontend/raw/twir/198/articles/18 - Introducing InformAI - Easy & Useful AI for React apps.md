# Item 18: Introducing InformAI - Easy & Useful AI for React apps

Source: [https://edspencer.net/2024/8/26/introducing-inform-ai](https://edspencer.net/2024/8/26/introducing-inform-ai)

Summary:
InformAI is a library that enables seamless integration of AI (LLMs) into React apps by exposing component state and UI events to AI agents. With minimal code, developers can make their app’s UI and state visible to LLMs, allowing for context-aware AI responses and UI generation, including support for React Server Components.

Key takeaways:
- InformAI exposes component state and events to LLMs for richer AI integration.
- Supports both client and server components; works with Vercel AI SDK.
- Enables gradual, non-intrusive adoption in existing apps.
- Ships with helper UI components for quick prototyping.
