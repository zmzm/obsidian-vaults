# Item 9: The magic of keeping one level of abstraction per function

Source: [https://www.tymzap.com/blog/the-magic-of-keeping-one-abstraction-level-per-function](https://www.tymzap.com/blog/the-magic-of-keeping-one-abstraction-level-per-function)

Summary:
This post advocates for maintaining a single level of abstraction within each function or component, using a user profile example in React. By extracting lower-level logic into separate functions, code becomes more readable, maintainable, and reusable. The approach reduces cognitive load and makes future changes safer and easier.

Key takeaways:
- Mixing abstraction levels in a function/component leads to confusion and harder maintenance.
- Refactoring to single-level abstraction improves readability and separation of concerns.
- Smaller, focused functions are more reusable and easier to test or modify.
- The trade-off is more function hopping, but the benefits outweigh the downsides.
