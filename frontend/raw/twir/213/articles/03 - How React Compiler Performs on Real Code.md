# Item 3: How React Compiler Performs on Real Code

Source: [https://www.developerway.com/posts/how-react-compiler-performs-on-real-code](https://www.developerway.com/posts/how-react-compiler-performs-on-real-code)

Summary:
This article analyzes the real-world impact of the React Compiler (formerly React Forget), which aims to automate memoization and optimize re-renders. It explains the core problems with manual memoization (useMemo, useCallback), how the compiler addresses them, and presents benchmarks from applying the compiler to an existing app. The author discusses both the promises and limitations of the compiler, with practical code examples.

Key takeaways:
- React Compiler automates memoization, reducing the need for manual useMemo/useCallback.
- It transforms code at build time, aiming to prevent unnecessary re-renders.
- The article provides empirical results and discusses when the compiler helps or falls short.
- Useful for understanding the future of React performance optimizations.
