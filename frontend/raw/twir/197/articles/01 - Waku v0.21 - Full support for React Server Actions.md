# Item 1: Waku v0.21 - Full support for React Server Actions

Source: [https://waku.gg/blog/server-actions-are-here](https://waku.gg/blog/server-actions-are-here)

Summary:
Waku v0.21 now offers full support for React 19's server actions API, enabling developers to define and execute server-side logic directly from React components. The release covers inline server actions, actions imported from separate files, and invocation via form action props. The article provides practical examples and cautions about authentication and endpoint exposure. It also highlights integration with React APIs like useTransition, useActionState, and useOptimistic for enhanced UX.

Key takeaways:
- Full support for React 19 server actions, including inline and imported actions.
- 'use server' directive marks async functions as server actions; careful placement is required to avoid unintended endpoints.
- Server actions can be invoked via event handlers or form action props, with support for passing additional arguments using bind.
- Integration with React hooks for pending states, optimistic updates, and returned values.
