# Item 6: Framer Motion is now independent, introducing Motion

Source: [https://motion.dev/blog/framer-motion-is-now-independent-introducing-motion](https://motion.dev/blog/framer-motion-is-now-independent-introducing-motion)

Summary:
Framer Motion, the popular React animation library, is now an independent open-source project called Motion, with its own site (motion.dev) and branding. The project will expand beyond React, offering vanilla JS APIs and integrations for other frameworks. The move aims to foster a broader community, improve documentation, and ensure Motion's sustainability, with sponsorships supporting ongoing development.

Key takeaways:
- Framer Motion is now Motion, an independent project with a new home and branding.
- Motion will support vanilla JS and other frameworks, not just React.
- Improved documentation, search, and developer-focused features are planned.
- Sponsorships (e.g., Tailwind) will help sustain and grow the project.
