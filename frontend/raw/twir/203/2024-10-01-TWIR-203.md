# This Week in React #203 (MOC)

## TL;DR
- React 19 has renamed "Server Actions" to "Server Functions" to clarify that not all server-executed functions are actions
- Next.js is updating its dynamic APIs (cookies, headers, draftMode, searchParams, params) to be asynchronous, returning Promises instead of synchronous values
- Next.js introduces a new connection() API to replace the unstable_noStore() API
- Cloudflare announced 18 updates to the Workers platform, including persistent logs, private database connectivity, improved Node.js compatibility, and enhanced deployment features
- DMNO offers a comprehensive environment variable management solution for Next.js, addressing issues like type safety, secure sharing, leak detection, and dynamic/static config separation
