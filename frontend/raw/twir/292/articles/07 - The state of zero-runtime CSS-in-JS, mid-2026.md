# Item 7: The state of zero-runtime CSS-in-JS, mid-2026

Source: [https://dx-styles.dev/blog/state-of-zero-runtime-css-in-js/](https://dx-styles.dev/blog/state-of-zero-runtime-css-in-js/)

Summary:
A comprehensive overview of the zero-runtime CSS-in-JS landscape, mapping out libraries like vanilla-extract, Panda CSS, StyleX, next-yak, Linaria, dx-styles, and Griffel. The article explains why compile-time CSS-in-JS survived the shift to concurrent and server rendering, and offers practical migration advice for teams with legacy styled-components codebases or new design-system needs.

Key takeaways:
- Runtime CSS-in-JS is largely obsolete; compile-time solutions dominate due to React's architectural changes.
- Each library targets different use cases: atomic vs. semantic output, app vs. design system, code-first vs. config-first.
- Migration paths exist for styled-components users (next-yak, Linaria), and interop between some libraries is possible.
- The field is converging on class-name strings and build-time evaluation; build performance is the new differentiator.
