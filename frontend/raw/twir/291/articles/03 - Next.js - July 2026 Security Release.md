# Item 3: Next.js - July 2026 Security Release

Source: [https://nextjs.org/blog/july-2026-security-release](https://nextjs.org/blog/july-2026-security-release)

Summary:
Next.js released security updates for multiple high- and medium-severity vulnerabilities affecting the App Router, Server Actions, Turbopack, and the Image Optimization API. The release introduces a preannounced security patching model, and teams are urged to upgrade to the latest LTS or canary/preview releases. Vulnerabilities include denial of service, SSRF, middleware/proxy bypass, and cache confusion issues.

Key takeaways:
- Multiple CVEs addressed; high-severity issues include DoS via Server Actions and SSRF in rewrites and Server Actions.
- All teams should upgrade to v16.2.11 (Active LTS), v15.5.21 (Maintenance LTS), or the latest canary/preview releases.
- The new security release model allows teams to plan for upcoming patches.
