# Item 6: Cache Components in Next.js 16

Source: [https://certificates.dev/blog/cache-components-in-nextjs](https://certificates.dev/blog/cache-components-in-nextjs)

Summary:
Next.js 16 introduces Cache Components, shifting the default from implicit caching to explicit, developer-controlled caching via the "use cache" directive. Data is dynamic by default, and developers must opt-in to caching at the component, file, or function level. The post explains how to enable the feature, cache data, and combine streaming, caching, and blocking for optimal rendering and performance.

Key takeaways:
- Caching is now explicit: data is dynamic unless "use cache" is specified.
- "use cache" can be applied at multiple scopes (file, component, function).
- Integrates with Partial Prerendering (PPR) and improves control over dynamic/static data.
- Migration requires code changes but offers clearer, more predictable caching.
