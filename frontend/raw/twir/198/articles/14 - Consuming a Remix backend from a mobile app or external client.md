# Item 14: Consuming a Remix backend from a mobile app or external client

Source: [https://www.jacobparis.com/content/remix-external-client](https://www.jacobparis.com/content/remix-external-client)

Summary:
This article explains why Remix route loaders and actions should not be reused for external clients (e.g., mobile apps). Instead, it recommends creating dedicated API/resource routes for external consumption, allowing for proper authentication, error handling, and separation of concerns.

Key takeaways:
- Route loaders/actions are intended for internal app use, not external clients.
- API/resource routes should be created for external access.
- Enables different authentication and error handling strategies.
- Shared logic can be extracted into common functions.
