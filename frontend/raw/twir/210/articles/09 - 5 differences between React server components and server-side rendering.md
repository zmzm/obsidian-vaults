# Item 9: 5 differences between React server components and server-side rendering

Source: [https://www.tymzap.com/blog/5-differences-between-react-server-components-and-server-side-rendering](https://www.tymzap.com/blog/5-differences-between-react-server-components-and-server-side-rendering)

Summary:
This article outlines five key differences between React Server Components (RSC) and traditional server-side rendering (SSR): bundle size, hydration process, component tree rendering, component lifecycle, and data fetching. RSC reduces client bundle size and eliminates hydration for non-interactive parts, while SSR requires full hydration and sends more JavaScript to the client. The article provides practical examples and highlights the architectural implications of each approach.

Key takeaways:
- RSC minimizes client bundle size and avoids hydration for static parts.
- SSR requires hydration and sends the full app bundle to the client.
- RSC and SSR differ in lifecycle hooks and data-fetching strategies.
- Migrating from SSR to RSC may require significant architectural changes.
