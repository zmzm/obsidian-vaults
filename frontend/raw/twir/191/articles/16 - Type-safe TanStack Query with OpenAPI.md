# Item 16: Type-safe TanStack Query with OpenAPI

Source: [https://ruanmartinelli.com/blog/tanstack-query-openapi](https://ruanmartinelli.com/blog/tanstack-query-openapi)

Summary:
This guide shows how to generate TypeScript types from an OpenAPI spec and use them to create type-safe TanStack Query hooks in React. It covers generating types, setting up an API client, and building strongly-typed hooks for queries and mutations, enabling end-to-end type safety without modifying the backend.

Key takeaways:
- openapi-typescript and openapi-fetch generate types and a type-safe API client from OpenAPI specs.
- Custom hooks wrap TanStack Query's useQuery/useMutation with full type inference.
- Enables "middle-to-end" type safety, similar to tRPC but backend-agnostic.
- Includes automation tips for keeping types in sync with API changes.
