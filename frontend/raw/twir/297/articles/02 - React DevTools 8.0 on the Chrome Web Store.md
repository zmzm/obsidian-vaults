# Item 2: React DevTools 8.0 on the Chrome Web Store

Source: [https://chromewebstore.google.com/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi?hl=en](https://chromewebstore.google.com/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi?hl=en)

Summary:
React DevTools 8.0 is now available on the Chrome Web Store, providing developers with enhanced tools for inspecting and debugging React component hierarchies and profiling performance. The extension adds "Components" and "Profiler" tabs to Chrome DevTools, allowing inspection and editing of props and state, as well as performance recording. The tool is open source, privacy-conscious, and maintained by Meta.

Key takeaways:
- New version (8.0.0) of React DevTools is available for Chrome, supporting component inspection and performance profiling.
- The extension does not transmit user data and is fully open source.
- Useful for debugging component trees and optimizing React app performance.
