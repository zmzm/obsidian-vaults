# Item 10: Exploring the HTML-in-Canvas Proposal

Source: [https://tympanus.net/codrops/2026/05/13/exploring-the-html-in-canvas-proposal/](https://tympanus.net/codrops/2026/05/13/exploring-the-html-in-canvas-proposal/)

Summary:
This article introduces an experimental browser proposal allowing real HTML content to be rendered inside a <canvas> element, preserving accessibility and CSS styling. The API provides primitives for layout, rendering, and paint events, enabling new use cases like post-processing effects, transitions, and 2D UIs within 3D scenes. The feature is currently behind a flag in Chromium browsers, and the post explores practical demos and potential applications for React developers.

Key takeaways:
- HTML-in-Canvas bridges the gap between DOM-based UIs and canvas rendering, supporting accessibility and styling.
- Enables advanced effects (e.g., shaders, transitions) on standard HTML content.
- API is experimental and requires enabling a browser flag.
- Opens new UI/UX possibilities for React apps using canvas or 3D libraries.
