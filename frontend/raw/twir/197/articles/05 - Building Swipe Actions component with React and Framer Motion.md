# Item 5: Building Swipe Actions component with React and Framer Motion

Source: [https://sinja.io/blog/swipe-actions-react-framer-motion](https://sinja.io/blog/swipe-actions-react-framer-motion)

Summary:
This tutorial demonstrates building a composable, unstyled Swipe Actions component (like iOS mail swipe actions) using React and Framer Motion. It outlines the component structure, use of the useSnap hook, and reliance on React Context for shared state. The guide provides step-by-step setup, code organization, and extensibility tips.

Key takeaways:
- SwipeActions is built as a set of composable primitives, inspired by Radix Primitives.
- Uses Framer Motion for animation and react-use-motion-measure for responsive sizing.
- State and refs are shared via React Context, enabling flexible composition.
- The component is unstyled for maximum reusability and customization.
