# TWIR 209

TWIR #209 is an older issue around non-blocking prerendering, the experimental `react-server` package, Next.js cache invalidation APIs, React Compiler adoption at Sanity, FormData, safer HTML, and offline TanStack Query.

## Summary

- React prerendering and `react-server` support the custom RSC/framework branch.
- Sanity's compiler adoption is an early production case for React Compiler benefits and constraints.
- Next.js cache invalidation, FormData, `dangerouslySetInnerHTML` hardening, and offline TanStack Query support several existing wiki branches.

## Why This Source Matters

- It is a strong bridge between React core rendering, RSC infrastructure, compiler adoption, and client-data reliability.

## Caveats

- Some Next.js cache API names later changed, so use newer pages for current implementation details.
