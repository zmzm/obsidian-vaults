# Item 15: Authoring CSS in modern JavaScript apps

Source: [https://www.alexchantastic.com/modern-css-authoring](https://www.alexchantastic.com/modern-css-authoring)

Summary:
This overview surveys current approaches to writing CSS in JS apps, including plain CSS, preprocessors (SASS/LESS), CSS Modules, and their tradeoffs. It discusses the evolution of CSS features, the decline of preprocessors, and the benefits of local scoping with CSS Modules. Practical code examples illustrate each method.

Key takeaways:
- Plain CSS is simple and performant but lacks local scoping.
- Preprocessors add features but are less necessary with modern CSS.
- CSS Modules solve global scope issues and are well-suited for large projects.
- The landscape is diverse; no single approach dominates.
