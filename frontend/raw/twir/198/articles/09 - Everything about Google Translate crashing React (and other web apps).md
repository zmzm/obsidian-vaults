Source: [https://martijnhols.nl/gists/everything-about-google-translate-crashing-react](https://martijnhols.nl/gists/everything-about-google-translate-crashing-react)

Summary:
This article details how Google Translate (and similar browser extensions) can break React apps by manipulating the DOM, replacing text nodes, and causing issues like stale content and crashes. It explains the underlying mechanisms, provides reproduction examples, and discusses the risks and possible workarounds for developers.

Key takeaways:
- Google Translate replaces text nodes with new elements, breaking React’s virtual DOM assumptions.
- Leads to issues like content not updating and NotFoundError crashes.
- Impacts all major JS frameworks, not just React.
- Manual testing and simulation techniques are provided; workarounds are discussed.
