# Item 3: Remix Route Convention Evolution

Source: [https://github.com/brookslybrand/route-convention-evolution](https://github.com/brookslybrand/route-convention-evolution)

Summary:
This resource documents the evolution of routing conventions from Remix v1’s nested folders to Remix v2’s flat file structure, and now to React Router v7’s explicit route configuration in code. The new approach separates layout components and route definitions, improving clarity and maintainability. The post provides concrete examples of each convention, showing how complex route hierarchies can be represented in both file structure and code.

Key takeaways:
- React Router v7 moves to explicit, code-based route configuration.
- Layouts are now defined as separate components, not tied to file/folder structure.
- Flat file routing replaces deeply nested folders, simplifying large apps.
- Examples provided for migration and comparison between conventions.
