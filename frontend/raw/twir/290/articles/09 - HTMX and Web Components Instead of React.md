# Item 9: HTMX and Web Components Instead of React

Source: [https://kore-nordmann.de/blog/htmx-and-web-components-instead-of-react.html](https://kore-nordmann.de/blog/htmx-and-web-components-instead-of-react.html)

Summary:
This post explains why a data platform project chose HTMX and Web Components over React, emphasizing the benefits of server-driven state, reduced duplication, and improved accessibility. HTMX is used for fragment-based updates without client-side state, while Web Components provide interactivity only where necessary, leveraging semantic HTML and browser features for accessibility.

Key takeaways:
- HTMX enables server-rendered, fragment-based updates without SPA overhead.
- Web Components are used sparingly for genuinely interactive UI parts.
- Semantic HTML and native elements improve accessibility by default.
- The approach avoids duplicating state and logic between client and server.
