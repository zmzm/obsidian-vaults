# Item 17: Exploring an experimental Micro-Frontend Architecture with Server-Side Rendering using React Server Components

Source: [https://dev.to/lazarv/exploring-an-experimental-micro-frontend-architecture-with-server-side-rendering-using-react-server-components-2d0f](https://dev.to/lazarv/exploring-an-experimental-micro-frontend-architecture-with-server-side-rendering-using-react-server-components-2d0f)

Summary:
The post explores combining micro-frontend architecture with React Server Components (RSC) and SSR. It discusses the benefits (scalability, performance, code-splitting) and challenges (complexity, shared state, dependencies) of this approach, and introduces an experimental implementation using @lazarv/react-server.

Key takeaways:
- Micro-frontends + RSC enable independent deployment, SSR, and fine-grained code-splitting.
- Shared state and dependency management are major challenges.
- Performance and SEO can be improved, but complexity increases.
- Experimental tooling is emerging to support these patterns.
