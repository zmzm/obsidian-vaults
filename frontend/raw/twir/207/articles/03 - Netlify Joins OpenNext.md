# Item 3: Netlify Joins OpenNext

Source: [https://www.netlify.com/blog/netlify-joins-opennext/](https://www.netlify.com/blog/netlify-joins-opennext/)

Summary:
Netlify is moving its open-source Next.js adapter to the OpenNext project, collaborating with other providers to improve portability and flexibility for Next.js deployments. This change aims to ensure Next.js runs well across various cloud platforms, not just Vercel. For most Netlify users, no immediate changes are required, but those manually installing the runtime package will need to update in the future.

Key takeaways:
- Netlify’s Next.js adapter is now part of OpenNext for better cross-provider compatibility.
- No immediate action is needed for most users; manual installers will need to update package names later.
- Older runtime versions lack support for recent Next.js features; upgrading is recommended.
- OpenNext fosters collaboration across cloud providers, benefiting the Next.js ecosystem.
