# Item 1: Next.js 15 RC 2

Source: [https://nextjs.org/blog/next-15-rc2](https://nextjs.org/blog/next-15-rc2)

Summary:
Next.js 15 Release Candidate 2 introduces several new features and improvements, including an automated codemod CLI for smoother upgrades, Turbopack performance gains, breaking changes to async request APIs, enhanced server action security, and new development tools like a static route indicator. The release focuses on developer experience, performance, and security, while preparing for the upcoming stable release. Key breaking changes and migration tools are highlighted, especially for those using request-specific APIs.

Key takeaways:
- Automated codemod CLI streamlines upgrades to Next.js 15 and React.
- Turbopack for development is nearing stability, with significant performance improvements.
- Request-specific APIs (e.g., cookies, headers) are now asynchronous, requiring code changes.
- Server Actions gain improved security through dead code elimination and secure, unguessable IDs.
- New development features: static route indicator, next/form for enhanced forms, TypeScript config support, and improved build/linting.
