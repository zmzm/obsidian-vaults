# Item 7: Architectural Patterns for Generative UI in React

Source: [https://boda.sh/blog/generative-ui/](https://boda.sh/blog/generative-ui/)

Summary:
This talk summarizes the evolving landscape of "Generative UI"—user interfaces generated or adapted by AI—categorizing approaches as Static/Controlled, Declarative, or Open-ended. It discusses practical and technical considerations, such as the risks of executing arbitrary code, the use of JSON schemas for safe declarative UIs, and gradual adoption patterns. The article contextualizes GenUI in both Western and Eastern tech ecosystems, highlighting the growing need for intent-based, flexible UI generation as AI becomes more integrated into products.

Key takeaways:
- Generative UI spans static, declarative, and open-ended approaches, each with trade-offs in flexibility and safety.
- Declarative GenUI (e.g., JSON schemas + SDKs) enables safe, dynamic UI generation without arbitrary code execution.
- Adoption can be incremental, starting with mapping AI outputs to existing components before moving to more open-ended solutions.
- The trend is driven by increasing complexity and the need for intent-based, adaptive interfaces as AI capabilities grow.
