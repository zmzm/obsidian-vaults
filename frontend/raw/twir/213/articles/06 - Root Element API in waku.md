# Item 6: Root Element API in waku

Source: [https://waku.gg/blog/root-element-api](https://waku.gg/blog/root-element-api)

Summary:
Waku introduces a root element API, allowing customization of the <html>, <head>, and <body> elements in both file-based and config-based routing setups. Developers can now define root-level attributes and layouts more flexibly, supporting both static and dynamic rendering strategies. The API is available in recent patch versions and is part of ongoing rearchitecture efforts.

Key takeaways:
- Custom root elements can be defined via _root.tsx or config-based createRoot.
- Supports both static and dynamic rendering.
- Enables setting global attributes and structure at the root level.
- Part of broader improvements in Waku's architecture.
