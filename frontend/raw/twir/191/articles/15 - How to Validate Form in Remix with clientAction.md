# Item 15: How to Validate Form in Remix with clientAction

Source: [https://sergiodxa.com/tutorials/validate-form-in-remix-with-clientaction](https://sergiodxa.com/tutorials/validate-form-in-remix-with-clientaction)

Summary:
This tutorial explains how to implement progressive form validation in Remix, starting with server-side validation, then adding HTML5 validations, and finally using the new clientAction API for client-side validation before submitting to the server. The approach allows for improved UX without relying on third-party form libraries.

Key takeaways:
- Start with server-side validation for security, then layer HTML5 and client-side validation.
- clientAction enables custom client-side validation logic before server submission.
- Can integrate with Zod for schema validation and React Aria for accessible error UI.
- Encourages progressive enhancement and minimal dependencies.
