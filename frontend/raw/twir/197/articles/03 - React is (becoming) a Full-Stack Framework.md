# Item 3: React is (becoming) a Full-Stack Framework

Source: [https://www.robinwieruch.de/react-full-stack-framework/](https://www.robinwieruch.de/react-full-stack-framework/)

Summary:
React's evolution with Server Components and Server Actions is transforming it into a full-stack framework, bridging frontend and backend. The article traces the historical context, the impact of TypeScript, and the shift from REST and tRPC to direct server logic in React. It emphasizes the new paradigm where React developers can implement vertical features from UI to database, with meta frameworks like Next.js leading the way.

Key takeaways:
- Server Components and Server Actions enable direct server-side logic and data access from React.
- TypeScript adoption raised expectations for type safety, exposing REST's limitations and fueling RPC/tRPC popularity.
- Next.js and similar frameworks are integrating these primitives, allowing full-stack workflows.
- Developers will need to learn backend best practices as React's scope expands beyond CRUD.
