# Item 8: Next.js August 2026 Security Release

Source: [https://nextjs.org/blog/august-2026-security-release](https://nextjs.org/blog/august-2026-security-release)

Summary:
Next.js released critical security updates addressing remote code execution vulnerabilities in the Image Optimization API (AVIF) and on Windows-hosted servers. The update disables AVIF optimization and patches filesystem-related issues, urging all users to upgrade immediately.

Key takeaways:
- Critical vulnerabilities fixed in Next.js v16.3.3 and v15.5.24.
- AVIF image optimization is disabled until upstream fixes are available.
- Windows-hosted servers with both Pages and App Router are affected by a separate RCE vulnerability.
- Users should upgrade dependencies promptly to maintain security.

Recommendation:
Read fully (read fully if maintaining Next.js apps, especially on Windows or using AVIF images)
