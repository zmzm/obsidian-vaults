# Item 3: Enhancing SEO in Flutter Web Projects with Next.js Integration

Source: [https://gist.github.com/lcw99/ac1738cb6d5bb032085077605f56665e](https://gist.github.com/lcw99/ac1738cb6d5bb032085077605f56665e)

Summary:
This guide addresses the SEO limitations of Flutter web apps by embedding them within a Next.js project. By leveraging Next.js server-side rendering, developers can serve SEO-friendly content to crawlers while regular users are redirected to the Flutter app. The article includes practical integration steps and emphasizes the importance of using path-based URLs for better SEO.

Key takeaways:
- Flutter web apps have poor SEO due to static, JS-heavy output.
- Embedding Flutter builds in Next.js allows dynamic meta tags and crawler detection.
- Server-side rendering in Next.js can serve alternate content to bots for better indexing.
- Switching Flutter to path-based URLs (via url_strategy) is crucial for SEO.
