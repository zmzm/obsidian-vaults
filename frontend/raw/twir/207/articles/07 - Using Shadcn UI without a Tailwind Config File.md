# Item 7: Using Shadcn UI without a Tailwind Config File

Source: [https://www.luisball.com/blog/shadcn-ui-with-tailwind-v4](https://www.luisball.com/blog/shadcn-ui-with-tailwind-v4)

Summary:
This guide shows how to use Shadcn UI components with Tailwind CSS v4 in a Next.js 15 app, without a tailwind.config.js file. Instead, it leverages CSS variables and the new @theme directive to define custom colors and theming directly in global CSS. The approach simplifies setup, improves maintainability, and aligns with Tailwind v4’s CSS-first philosophy.

Key takeaways:
- Tailwind CSS v4 allows configuration via CSS variables and @theme, removing the need for tailwind.config.js.
- Shadcn UI theming can be managed entirely in global CSS using CSS variables.
- The approach is compatible with Next.js 15 and improves maintainability and performance.
- Useful for teams preferring CSS-based configuration over JavaScript files.
