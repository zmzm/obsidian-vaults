# This Week in React #204 (MOC)

## TL;DR
- Meta showcased how React and React Native are central to their product development, powering apps like Instagram, Facebook, and Meta Horizon for Meta Quest and other platforms
- Next.js v15.0.0-canary.171 introduces breaking changes to dynamic APIs (cookies, headers, draftMode, searchParams, params), making them asynchronous and returning Promises
- Vercel's new "serverless servers" feature enables in-function concurrency, allowing a single Node.js function instance to handle multiple concurrent requests, improving efficiency and reducing compute costs
