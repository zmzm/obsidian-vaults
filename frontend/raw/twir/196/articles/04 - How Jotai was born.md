# Item 4: How Jotai was born

Source: [https://blog.axlight.com/posts/how-jotai-was-born/](https://blog.axlight.com/posts/how-jotai-was-born/)

Summary:
The post recounts the motivation and process behind creating Jotai, a minimal React state management library inspired by Recoil but with a simpler API and no string keys. The author describes earlier experiments with proxies and context-based libraries, and how Jotai evolved to focus on a small, maintainable core with extensible integrations. Jotai is now stable, community-maintained, and continues to grow in features and adoption.

Key takeaways:
- Jotai was created to offer a minimal, flexible alternative to Recoil for state management.
- The library avoids the complexity of selectors and string keys, favoring simplicity.
- Emphasizes maintainability, extensibility, and a small core API.
- Jotai has matured into a stable, community-driven project.
