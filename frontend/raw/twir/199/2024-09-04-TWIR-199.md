# This Week in React #199 (MOC)

## TL;DR
- Shadcn UI has added new CLI commands for working with UI presets, making it easier to decode, resolve, share, and open preset configurations
- A pull request is in progress to add support for React’s new `use()` hook to TanStack Query, specifically for `useQuery()` and `useInfiniteQuery()`
- This resource documents the evolution of routing conventions from Remix v1’s nested folders to Remix v2’s flat file structure, and now to React Router v7’s explicit route configuration in code
- @svg-use is a new toolchain and set of bundler plugins for ergonomically loading SVGs as components using SVG’s `<use href>` mechanism, as an alternative to SVG-in-JS
- This post explores how React Server Components and build-time plugins can transform content-driven sites by enabling data enrichment (e.g., adding Open Graph images to links) at build time instead of client-side
