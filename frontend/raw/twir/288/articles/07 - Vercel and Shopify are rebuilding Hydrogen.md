# Item 7: Vercel and Shopify are rebuilding Hydrogen

Source: [https://vercel.com/blog/vercel-and-shopify-are-rebuilding-hydrogen](https://vercel.com/blog/vercel-and-shopify-are-rebuilding-hydrogen)

Summary:
Vercel and Shopify are collaborating to rebuild Hydrogen as an open-source, runtime-agnostic toolkit for headless commerce. The new Hydrogen separates concerns into core (API logic), client (state management), and server (framework integration), with React support available now and other frameworks planned. The approach centralizes common logic, encourages best practices, and provides documentation and skills for integration, especially with Next.js and Cache Components.

Key takeaways:
- Hydrogen is being rebuilt to be open-source and framework-agnostic.
- Core commerce logic, client state, and server integration are modularized.
- React client components are available now; other frameworks will follow.
- Guidance, templates, and skills facilitate integration with Next.js and headless Shopify.
