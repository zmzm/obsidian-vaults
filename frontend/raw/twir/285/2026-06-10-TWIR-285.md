# This Week in React #285 (MOC)

## TL;DR
- The React Foundation is a new community-driven initiative aimed at sustaining and advancing the React ecosystem
- This PR details an experimental, in-progress port of the React Compiler from TypeScript to Rust, aiming for improved performance and easier integration with Rust-based tooling
- This RFC proposes allowing useEffect and useLayoutEffect to return a disposable object (with a [Symbol.dispose] method) as their cleanup function, instead of just a callback
- Flow has evolved to closely match TypeScript’s syntax, making it easy for TypeScript users to adopt
- This article demonstrates building a reusable NavLink component for Next.js, inspired by React Router’s NavLink
