# Item 8: React Router – Changes Planned for v9

Source: [https://github.com/remix-run/react-router/discussions/15371](https://github.com/remix-run/react-router/discussions/15371)

Summary:
A discussion outlines the roadmap for React Router v9, targeting a mid-2027 release. The goals include reducing API surface, providing simple migration paths, and maintaining a regular release cadence. Planned changes involve stabilizing new hooks (useRoute, useRouterState), deprecating older APIs, updating minimum supported versions, and possibly removing legacy flags. Community feedback is solicited on several proposals.

Key takeaways:
- v9 will focus on API simplification and clear migration paths.
- New hooks (useRoute, useRouterState) to be stabilized; older hooks may be deprecated.
- Minimum Node and possibly React/Vite versions will be updated.
- Some features (like View Transition APIs) may be deprecated in favor of React-native solutions.
- Community input is encouraged for pending decisions.
